# Smol Maiden Discord Bot
* What's Smol Maiden?
Smol Maiden#1515 is a discord bot made using [Discord.js](https://discord.js.org/#/) and some node modules.
The only support and testing server is [here](https://discord.gg/2SatpX28ZX).
Smol Maiden is now **free and open source** — use it, modify it, self-host it! 🩷

* Smol Maiden is made using [Expectative's Discord.js bot example](https://github.com/Expectatives/Discord.js-v13-Example/), big thanks to them.

# Dependencies
* [Node.js](https://nodejs.org/en/) (18+)
* [npm](https://www.npmjs.com)

# Self-hosting
1. Clone this repository
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in your bot token (and MongoDB URI, if you need it)
4. Start the bot with `npm start`
